# Smart Campus Project 

## Overview
This is a C++ project that manages smart devices in a campus. It can handle devices in two ways: 
1. Global devices (like the front door lock).
2. Room-specific devices (loaded from a file).

## How the File Works (Requirements)
The system starts by reading from `Devices.txt`. I chose a "pipe" format (`|`) to separate the data because it prevents errors if a device name has a space in it.

**File Format:** Room | Device Type | ID | Name | Brand | Extra Info
**Example:** Classroom_A|Projector|101|Main_Projector|Sony|HDMI

## Design Patterns Used
To get the extra points for design, I implemented these four patterns:

1. **Strategy Pattern:** This is in the interaction_event(). It lets me call one function on any device, but the result changes depending on if it's a Camera or a Light.
2. **Composite Pattern:** This is the Hybrid structure. My code treats individual global devices and the devices inside Rooms as one big system.
3. **Factory Logic:** In LoadFromFile, the code looks at the Type string (like Projector) and decides which specific object to create.
4. **Iterator Pattern:** I used this in the DeleteDevice function to safely move through the vectors without the program crashing.

## How to Run

Open your terminal.

Navigate to the project folder: cd Path/To/SmartCampus

Compile: g++ -std=c++17 -o smart_campus main.c++ SourceFiles/*.c++

Run: ./smart_campus
